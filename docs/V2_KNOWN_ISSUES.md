# Network Locator V2 已知问题清单

> 版本：1.4.0  
> 最后更新：2026-11-25

## 产品与能力边界

1. **只发现二层可达设备。** 应用依赖 NAS 所在广播域，跨 VLAN、跨路由
   设备通常只会显示为网关 MAC。README 与隐私说明已声明该边界。
2. **厂商库是常见 LAN 设备的子集，共 205 个前缀。** 未收录前缀显示
   “未知厂商”，不会猜测。MAC 前缀查询只能确认 OUI，不能确认具体型号。
3. **MAC 冲突与随机 MAC 无法 100% 自动判定。** 已实现随机 MAC 标记、
   MAC 优先 + IP/接口 7 天兜底，以及事件记录；极端冲突场景仍可能需要
   人工在详情抽屉中改名区分。
4. **预览默认扫描很快。** 本地预览默认约 1 秒完成，手动暂停通常落在完成之后；
   需要演示暂停/恢复时使用 `--scan-step-delay` 放慢进度。真实 NAS 上已验证
   暂停→恢复→停止并保留结果。
5. **离线判定需要一次完整清单扫描。** 只做 MAC 后缀查询不会把其他设备
   标记为离线，这是避免误判的设计选择。

## 界面与兼容

6. **测试浏览器视口为 1081×881。** TOS 实际窗口默认 1180×720。1180 宽
   下设备表已无横向滚动；1081 宽时导航仍为 210px；760/620 宽时导航折叠
   为 72px，设备表按优先级隐藏厂商、最近发现、状态和操作列，详情仍可
   通过行点击或“详情”按钮打开。
7. **部分宽度仍有表格内部横向滚动兜底。** 1180 与 620 宽为 0；1081 宽
   Dashboard/Inventory 约 25px/8px，760 宽约 14px/21px。页面本身不横向
   溢出，属于表格内部滚动，不阻塞使用。
8. **“网络扫描”页已由 V2 重做。** 支持多网段、自定义 CIDR、进度、暂停/恢复/停止、
   实时结果、50 条分页与完整 CSV；旧“我的设备”保存的 MAC 后缀与备注迁入
   “MAC 定位”页，继续使用同一 `localStorage` 键。
9. **英文模式已覆盖 7 个页面、抽屉、空/加载/错误态与预览样例数据。**
   设备名称、备注等用户输入文本保持用户原样；生成型文案、状态原因、
   事件详情和中文标点会按英文规则输出。表格中的超长英文设备名会以
   省略号收束，悬停标题与详情抽屉显示全名。
10. **旧版 localStorage 记录不会自动迁移到 SQLite。** 保存的 MAC 后缀与备注
    由“MAC 定位”页继续读写；旧网络选择、面板尺寸等键保留但不再使用。
    V2 设备档案从首次扫描建立。

## 打包与部署

11. **AArch64 Deb 不能复用 x86_64 的 TDP 应用条目。** 平台侧一个 App ID
    只能绑定一种架构；ARM 上架需要单独身份，等待所有者决策。
12. **卸载会删除应用数据。** `remove`/`purge` 清理
    `/usr/local/network-locator/` 与 socket，卸载前需导出 CSV。
13. **真机回归仍待执行。** 本阶段只做本地预览、单元测试与双架构 Deb
    构建；发布前需在 TOS 7.1 NAS 上完成安装、启动、入口、7 个页面、真实
    网络扫描与卸载回归；截至第 7 步仍未获得机器窗口。
14. **大量数据只验证到 10,009 条。** Dashboard、Inventory 与网络扫描结果均每页
    50 条；10,009 条扫描结果分页显示 `Page 1 · 1–50 / 10009`，CSV 导出
    表头 + 10,009 行。更高数量级或低内存真机仍需压测。
15. **预览服务器的自定义范围会替换为示例网段。** 界面会明确提示未执行真实探测；
    生产后端按用户输入的真实 CIDR / 起止地址扫描。

16. **MAC 批量查询上限 100 行 / 次。** 界面对超限输入直接提示并拦截；
    每页 50 条，批量分组各自分页，更多条目需分批提交。
17. **MAC 定位的实时扫描叠加结果不写入档案。** 仅在未分页的第一页展示，
    并标注 `live_not_persisted`；长期保留需执行设备清单扫描。

18. **网络分析与扫描历史的预览数据是样例。** 预览服务器会明确标注 sample，
    不进入 Deb；生产后端使用系统接口、DNS、ping 与 SQLite 扫描记录，读取
    或命令失败会显示错误，不会伪装成功。
