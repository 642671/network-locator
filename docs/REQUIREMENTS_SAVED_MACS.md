# 需求：我的设备（保存 MAC 与当前 IP）

状态：已实现于 1.2.0。本文记录已确认的产品决策和验收标准。

## 背景

MAC 后缀固定不变，IP 会随 DHCP 变化；公司内设备多，用户在设备总表里很难快速找到自己的机器。用户希望保存自己的 MAC 后缀，以后打开应用就能直接看到当前 IP，并一键使用；同时保留通用 MAC 搜索，让其他人也能查找自己的设备。

## 已确认的决策

| 决策 | 结果 |
| --- | --- |
| 布局 | 页面分为「我的设备」和「设备总表」两个独立分区，「设备总表」标题紧贴设备列表 |
| 保存上限 | 8 条 |
| 身份 | 以 4 位 MAC 后缀为身份，IP 每次扫描动态解析 |
| 点击 IP | 复制 IP；旁边的 `↗` 在新标签页打开 `http://IP/` |
| 行点击 | 打开只读详情；铅笔按钮直接进入编辑 |
| 用途说明 | 可选，最多 100 字，纯文本渲染 |
| 完整 MAC | 首次匹配后缓存，用于后缀碰撞时优先匹配同一块网卡 |
| 持久化 | 浏览器 `localStorage`，键 `networkLocator.savedMacs.v1`，应用升级后保留 |
| 通用搜索 | 完全保留，保存面板不自动填入输入框、不自动发起搜索 |
| 版本 | 1.2.0 |

## 功能行为

1. 面板默认显示已保存的 MAC 后缀、用途、当前 IP、在线状态和最后发现时间。
2. 应用启动后先显示上次缓存的 IP，设备总表扫描完成后自动刷新为当前 IP。
3. 设备不在当前网段、未开机或未被发现时，显示「未发现」和上次 IP/时间。
4. 同一后缀命中多台设备时全部列出，并显示「N 台」提示，避免把后缀碰撞当成唯一设备。
5. 点击 IP 复制并提示；点击 `↗` 打开设备页面；点击行查看只读详情。
6. 「用于搜索」把该 MAC 填入搜索输入区，不自动开始扫描。
7. 新增/编辑/删除通过弹窗完成；删除和丢弃未保存修改需要确认。
8. 最多 8 条；重复 MAC（忽略大小写和分隔符）不能保存。
9. 没有保存记录时显示轻量空状态，不影响原有设备总表和搜索。
10. 保存列表只属于当前浏览器用户；其他人打开应用看到自己的列表。

## 数据模型

```json
{
  "version": 1,
  "updatedAt": 1795234567000,
  "items": [
    {
      "id": "m1a2b3c4",
      "display": "A1:B2",
      "normalized": "A1B2",
      "note": "客厅电视",
      "lastSeenIp": "10.0.0.25",
      "lastSeenFullMac": "0242AC11A1B2",
      "lastSeenInterface": "eth1",
      "lastSeenRange": "10.0.0.0/24",
      "lastSeenAt": 1795234567000,
      "createdAt": 1795234000000,
      "updatedAt": 1795234567000
    }
  ]
}
```

读取时做防御性清洗：格式、去重、8 条上限、备注长度、ID 冲突；损坏数据忽略。

## 边界与限制

- 4 位后缀只有 16 bit，机器多时可能碰撞，界面必须展示全部匹配。
- 保存的是后缀；完整 MAC 只作为最近一次匹配的消歧缓存。
- 浏览器清除站点数据、隐私模式、换浏览器或换设备会丢失列表。
- 同一浏览器多人共用会看到彼此的列表。
- 跨设备同步需要后端按 TOS 用户存储，不在本版本范围。

## 验收标准

- 保存 3 条，刷新后仍显示，顺序和用途一致。
- 设备 IP 变化后刷新，显示新 IP；设备离线显示上次 IP 和「未发现」。
- 同一后缀两台设备时两条 IP 都显示，并标记「2 台」。
- 点击 IP 复制成功；`↗` 打开 `http://IP/`。
- 编辑、删除、8 条上限、重复拦截、用途 100 字限制正常。
- 另一浏览器打开看不到别人的列表，通用搜索正常。
- 安装新版本覆盖旧版本后列表和备注保留。
- 禁用 localStorage 时页面可用并提示不会保留。
- 800×720、1120×720、1280×900，浅色/深色下布局正常。
- 用途说明输入 HTML 时按纯文本显示，不执行。

- 面板改为全宽区域，与工作区标题、表格边界一致。

- 刷新「我的设备」当前 IP 时在列表顶部显示一条带扫光的加载行，按钮显示「刷新中…」，
  列表标记为刷新中，完成后提示「当前 IP 已刷新」。

- 标题栏与 favicon 使用新的地球定位图标。
